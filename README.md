# 🏫 Laravel Piket App

Aplikasi berbasis web untuk mengelola dan memantau jadwal serta laporan piket harian secara terstruktur. Dibangun menggunakan framework Laravel dengan sistem manajemen peran (*Role-Based Access Control*).

## 🚀 Fitur Utama
- **Multi-Role Authentication**: Hak akses terpisah untuk **Admin** dan **Petugas**.
- **Manajemen Jadwal**: Pengaturan jadwal piket harian/mingguan.
- **Sistem Pelaporan**: Pengiriman dan pengelolaan laporan harian piket.
- **Spatie Permission**: Integrasi manajemen *roles* dan *permissions* yang aman.

## 🛠️ Tech Stack
- **Framework:** Laravel
- **Database:** MySQL
- **Frontend:** Blade Templating, Bootstrap / CSS
- **Authorization:** Spatie Laravel Permission
